## Phase P3 - Report screen

**Status:** active.
**Depends on:** P0 (`../done/P0-design-tokens-brand-shell.md`). Reads (but does not
change) the `Report` shape frozen by the `report-fidelity` plan.
**Scope:** restyle `#report`'s existing structured output into the Kuulustelupöytäkirja
direction (D1) — the concept document as a bordered "case file" card, the evaluation
profile as a status-grid of area cards with a verdict-colored left border, the risk
register with retokenized priority badges, and the final recommendation as a tilted
stamp (green/gold/rust by recommendation), matching `full-plan.md`'s own scoped
description ("paper-card concept document, status-grid evaluation profile, and
prioritized risk register from the direction, plus the recommendation stamp"). No
change to `#idea-form` or `#chat`, no change to `app/`, no change to what data reaches
`renderReport` (the `Report` shape is frozen and untouched).
**Gate level:** standard - purely additive/restyling frontend markup/JS/CSS; no
API/schema change, no new data flows into the report, no invariant touched (matches
P0/P1's gate level; P2 was `full` only because of D6's backend field, which does not
recur here).
